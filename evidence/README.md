# Screenshot evidence

These are selected screenshots from my Windows forensic investigation, arranged in the order used by the [walkthrough](../WALKTHROUGH.md).

The public copies have been cropped or redacted where needed to remove local paths, personal filenames, names in spreadsheets and the output of a filename-derived hash used as a container credential. Redactions are visible. No original disk images, recovered documents, archives, passwords or keys are stored here.

The screenshots show the observed application state, but they are not a substitute for original evidence files or a complete forensic chain of custody.
